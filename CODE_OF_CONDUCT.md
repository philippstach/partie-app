# Code of Conduct / Verhaltenskodex

## English

Partie is a project for games played together, and we want working on it to feel the same way.

- Be friendly, patient and respectful, also when you disagree.
- Criticise ideas and code, never people.
- No harassment, insults, discrimination, sexualised language or personal attacks, in any language.
- Do not publish other people's private information.

Maintainers may edit or remove comments, issues and contributions that break these rules, and may block people who repeatedly do so.
Report problems privately via **Security → Report a vulnerability** or by contacting the maintainer on GitHub.

Inspired by the [Contributor Covenant](https://www.contributor-covenant.org).

## Deutsch

Partie ist ein Projekt für Spiele, die man zusammen spielt, und so soll sich auch die Arbeit daran anfühlen.

- Freundlich, geduldig und respektvoll bleiben, auch bei Meinungsverschiedenheiten.
- Ideen und Code kritisieren, nie Menschen.
- Keine Belästigung, Beleidigung, Diskriminierung, sexualisierte Sprache oder persönlichen Angriffe, in keiner Sprache.
- Keine privaten Daten anderer veröffentlichen.

Wer das Projekt betreut, darf Kommentare, Issues und Beiträge, die gegen diese Regeln verstoßen, bearbeiten oder entfernen und Personen sperren, die das wiederholt tun.
Probleme bitte vertraulich über **Security → Report a vulnerability** melden oder die betreuende Person auf GitHub ansprechen.

Angelehnt an den [Contributor Covenant](https://www.contributor-covenant.org).
