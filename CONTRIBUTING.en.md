# Contributing to Partie

[Deutsch](CONTRIBUTING.md)

Thanks for helping! Bug fixes, improvements to the shared toolkit, translations and ideas are welcome. **Before version 1.0 we do not accept new games or changes to individual games.**

## Ground rules

- **No third-party libraries.** Partie uses only Apple frameworks (Swift, SwiftUI, Swift Charts, WidgetKit).
- **No ads, no tracking, no network calls** for gameplay. Everything runs offline.
- **Design:** use the shared "Klar & Glas" components from `Pakete/Baukasten` (product `KlarGlas`). No custom themes, no copied components.
- **Language:** code, identifiers and comments are in German. Issues and pull requests may be in English or German.
- **Names:** use neutral game names, never trademarks (e.g. "Yacht", not a brand name).

## Building

```bash
cp Lokal.xcconfig.beispiel Lokal.xcconfig   # your own Team ID
xcodegen
open Partie.xcodeproj
```

Each package can be tested on its own on a Mac, without a simulator:

```bash
cd Pakete/SpielYacht && swift test
```

Every package has a `README.md` with its test setup and environment variables.

## Where code contributions belong

Best in the shared toolkit `Pakete/Baukasten` (product `KlarGlas`): colors, sheets, buttons, thumbnails and the "Tinte" design. A change there is made once, and the app applies it to all games. Please open an issue first and briefly describe what should get better. Changes to individual games and new games are possible after 1.0 at the earliest; the guide will then be added here.

## Content

Puzzles, word lists, sounds and images must be your own work or generated by your own code. Do not copy from puzzle books, websites or dictionaries. Describe the origin in `HERKUNFT.md`. Sounds should come from a generator script (see `Werkzeug/Toene/`).

## Pull requests

- One topic per pull request. Describe what changed and how you tested it.
- All package tests must pass (`swift test`), and the app must build.
- **Sign off every commit** ([Developer Certificate of Origin](https://developercertificate.org)):
  ```bash
  git commit -s -m "Mühle: Computer erkennt Zwickmühlen"
  ```
  This adds `Signed-off-by: Your Name <mail>` and confirms that you have the right to submit the change.
