# Security / Sicherheit

## English

Partie runs entirely on the device. It has no accounts, no server and does not send game data anywhere. Player data and statistics stay on the device (and in the user's own iCloud backup).

If you find a security or privacy problem, please **do not open a public issue**. Report it privately via GitHub: **Security → Report a vulnerability** in this repository. You will get an answer within 14 days.

Supported version: the latest version in the App Store.

## Deutsch

Partie läuft vollständig auf dem Gerät. Es gibt keine Konten, keinen Server, und Spieldaten werden nirgendwohin geschickt. Spieler und Statistik bleiben auf dem Gerät (und in der eigenen iCloud-Sicherung).

Wenn du ein Sicherheits- oder Datenschutzproblem findest, eröffne bitte **kein öffentliches Issue**. Melde es vertraulich über GitHub: **Security → Report a vulnerability** in diesem Repository. Eine Antwort kommt innerhalb von 14 Tagen.

Unterstützte Version: die aktuelle Version im App Store.
